# FitLog — Workout Library

FitLog is a responsive workout library application that helps users explore workouts, view detailed exercise information, save workouts, and create a personalized workout plan.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- DaisyUI
- JavaScript
- Lucide React
- REST API
- LocalStorage

## Key Features

1. Workout Library
   - Browse a collection of workouts with exercise images, muscle groups, equipment, duration, calories, and ratings.

2. Workout Details
   - View complete workout information including difficulty, sets, reps, duration, calories, rating, description, and instructions.

3. Today's Workout Plan
   - Add workouts to a personalized plan and manage the selected exercises.

4. Saved Workouts
   - Save favorite workouts for later and easily access them from the My Plan section.

5. Responsive Design
   - Fully responsive interface optimized for mobile, tablet, and desktop devices.
